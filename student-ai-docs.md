# Student AI Assistant - Техническая документация

## Описание проекта

**Student AI Assistant** (MindeSync) — веб-платформа для автоматизированной обработки студенческих лекций и персонализированного тайм-менеджмента. Проект представляет собой frontend прототип для транскрибации аудиозаписей в текст с использованием AI технологий.

### Основная цель
Превращение аудиозаписей лекций, интервью и встреч в структурированный текст для дальнейшего изучения и анализа.

### Текущий статус
- ✅ Frontend прототип (React + TypeScript)
- ⏳ Backend интеграция (планируется)
- ⏳ AI обработка через Whisper API (в разработке)

## Компоненты приложения

### App.tsx
**Главный компонент приложения**

Управляет:
- Переключением темы (светлая/темная)
- Навигацией между страницами (home/auth)
- Композицией всех секций лендинга

```typescript
interface AppState {
  isLightTheme: boolean;    // Текущая тема
  currentPage: 'home' | 'auth'; // Текущая страница

```

### Header.tsx
**Навигационная шапка**

Функционал:
- Логотип с навигацией на главную
- Ссылки на секции страницы
- Кнопка входа в систему
- Переключатель темы (☀️/☾)

Props:
```typescript
interface HeaderProps {
  onToggleTheme: () => void;
  isLightTheme: boolean;
  onNavigateToAuth?: () => void;
  isAuthPage?: boolean;
```

### Hero.tsx
**Главная секция (Hero Section)**

Содержит:
- Заголовок и описание платформы

- Обработку ошибок

**Секция "Как это работает"**

Описывает процесс в 3 шага:
1. **Загрузите файл** - поддержка всех популярных форматов
2. **Обработка** - AI анализ и распознавание речи
3. **Получите текст** - скачивание готовой транскрипции

Включает интерактивные эффекты при наведении.

### UploadDemo.tsx
**Демонстрационный блок загрузки**

Функционал:
- Визуальная область для загрузки файлов
- Иконка загрузки с анимацией
- Прогресс-бар
- Обработка состояний (загрузка/успех/ошибка)

### Features.tsx
**Блок преимуществ платформы**

3 ключевые особенности:

- 🔒 **Защита данных** - шифрование файлов

## Хуки (Hooks)

### useFileUpload.ts
**Кастомный хук для загрузки файлов**

Управляет состоянием загрузки файлов на сервер.

```typescript
interface FileUploadState {
  isUploading: boolean;     // Идет ли загрузка
  uploadProgress: number;   // Прогресс 0-100%
  error: string | null;     // Текст ошибки
  success: boolean;         // Успешная загрузка
}
```

Методы:
- `uploadFile(file: File)` - загрузка файла
- `resetState()` - сброс состояния

**Текущая реализация:**
- Симуляция загрузки с прогрессом
- Автосброс состояния через 3 секунды
- Готово для интеграции с реальным API

**Будущая интеграция:**
```typescript
const response = await fetch('/api/upload', {
  method: 'POST',
  body: formData
});
```

## Планируемая архитектура API

### Endpoint для загрузки

```typescript
POST /api/upload
Content-Type: multipart/form-data

Body: {
  audio: File
}

Response: {
  success: boolean;
  fileId: string;
  status: 'processing' | 'completed' | 'failed';
}
```

### Endpoint транскрибации

```typescript
GET /api/transcription/:fileId

Response: {
  text: string;
  timestamps: Array<{time: number, text: string}>;
  confidence: number;
}
```

### Endpoint аутентификации

```typescript
POST /api/auth/login
Body: {
  username: string;
  password: string;
}

POST /api/auth/register
Body: {
  username: string;
  email: string;
  password: string;
}
```
