# Features

This page groups the product features by user value instead of implementation details.

## For students

- upload lecture recordings and get a text transcript
- clean the transcript with AI filters
- generate short or extended lecture summaries
- extract key terms with definitions
- produce revision questions and cheat sheets
- export study materials to PDF, DOCX, TXT, or Markdown

## For teachers

- turn lecture recordings into structured notes
- quickly generate question sets for review or exams
- prepare reference material for students
- share content through boards and catalog sections

## For self-learners

- convert podcasts, talks, and educational videos into readable notes
- use the worker locally for offline Whisper transcription
- keep materials organized by semester, discipline, and board

## Core processing features

- Whisper transcription runs locally on the machine or worker host
- AI post-processing uses DeepSeek through the configured provider
- board and catalog modules help organize learning content
- export support is available both in the frontend and through the PDF service

## System features

- authentication and role-based access
- admin dashboard with queue and worker statistics
- multi-worker support through worker keys
- heartbeat and recovery for long-running transcription jobs
- Docker-based deployment for the full stack

## Typical workflow

1. Upload a file.
2. Transcribe the audio.
3. Clean or enrich the text.
4. Generate a summary, glossary, questions, or cheat sheet.
5. Export the final result.

## 💬 Часто задаваемые вопросы

**Q: Сколько это стоит?**  
A: Транскрибация абсолютно бесплатна (работает локально)! AI-обработка требует API ключ VseLLM - стоимость зависит от использования (подробности на https://vsellm.ru).

**Q: Какие языки поддерживаются?**  
A: Русский язык (можно добавить английский и другие).

**Q: Какой максимальный размер файла?**  
A: До 100 МБ (~90 минут аудио хорошего качества).

**Q: Нужен ли интернет?**  
A: Для транскрибации - НЕТ (работает офлайн). Для AI-обработки - ДА (обращается к DeepSeek API через VseLLM).

**Q: Как точно работает распознавание?**  
A: Очень точно! Использует модель Whisper от OpenAI с точностью ~95% для русского языка.

**Q: Можно ли редактировать результат?**  
A: Да! Встроенный WYSIWYG редактор позволяет править текст как угодно.

**Q: Сохраняются ли мои файлы?**  
A: Пока нет функции облачного хранения, но вы можете экспортировать всё на свой компьютер.

**Q: Работает ли на телефоне?**  
A: Сейчас только веб-версия для компьютера. Мобильное приложение в планах!

## 🎯 Ограничения

**Текущие ограничения:**
- Транскрибация только на русском (английский скоро)
- AI-обработка требует интернет
- Проверьте баланс на платформе VseLLM (https://vsellm.ru)
- Нет облачного хранения файлов

**В планах добавить:**

### Транскрибация и аудио
- **Предобработка аудио** — нормализация громкости, удаление тишины, понижение шума через FFmpeg перед подачей в Whisper
- **Initial prompt по предмету** — если пользователь указывает предмет (например, «дискретная математика»), Whisper получит подсказку с терминологией и будет лучше распознавать специализированные слова
- **Диаризация (кто говорит)** — через `pyannote-audio` определять спикеров и выводить транскрипт в формате диалога (преподаватель / студент)
- **Живая транскрибация (real-time)** — запись прямо в браузере через `MediaRecorder API`, чанки отправляются на бэкенд через WebSocket, текст появляется во время лекции
- **Параллельная транскрибация** — разрезание длинного аудио на куски и обработка параллельно, пользователь видит первые результаты пока остальное ещё обрабатывается
- **Извлечение слайдов из видео** — определение моментов смены слайда через FFmpeg + попиксельное сравнение кадров, конспект привязывается к слайдам по таймкоду

### AI-обработка и стриминг
- **Стриминг ответов от DeepSeek** — вместо ожидания 30-60 секунд со спиннером, пользователь видит как конспект «пишется» в реальном времени (`stream=True` + SSE/ReadableStream)
- **Кэширование результатов ML** — хэш от (текст + режим) → сохранённый результат, чтобы не тратить токены при повторной обработке
- **Оффлайн AI-обработка** — fallback на локальную LLM через `ollama` (Qwen2.5-7B, Gemma-2-9B) для работы без интернета
- **Мультиязычный саммари** — транскрибация на языке оригинала + конспект на русском (полезно для англоязычных IT-курсов)

### Система знаний и хранение
- **Календарь пар и ДЗ** — сетка пар по расписанию, к каждой паре можно прикрепить лекцию, конспект, домашнее задание с дедлайном
- **База данных лекций** — PostgreSQL (Neon) для метаданных + Яндекс.Диск как хранилище файлов через REST API
- **Связь между лекциями** — при обработке новой лекции подгружать саммари предыдущих лекций того же предмета в контекст промпта
- **Граф знаний** — каждый термин как узел, визуализация связей между понятиями через `react-force-graph`
- **Семантический поиск** — эмбеддинги текстов через `sentence-transformers` + `pgvector`, поиск по смыслу а не по словам

### Обучение и совместная работа
- **Интерактивный тренажёр** — AI генерирует вопрос, студент отвечает, DeepSeek оценивает ответ и даёт обратную связь + spaced repetition
- **Автогенерация флеш-карточек Anki** — экспорт терминов в `.apkg` через `genanki`
- **Совместная работа** — общая база лекций группы, расшаривание конспектов по ссылке
- **Платформа обмена лекциями и коллаборативного редактирования** — социальная сеть для студентов с возможностями:
  * 🌐 **Публичная библиотека лекций** — маркетплейс конспектов с фильтрами по университету, предмету, преподавателю, рейтингу
  * 🔗 **Система шаринга** — генерация публичных/приватных ссылок на лекции с настройкой прав доступа (только просмотр / редактирование / комментирование)
  * 👥 **Real-time совместное редактирование** — как в Google Docs, несколько студентов одновременно редактируют конспект через WebSocket + CRDT (Conflict-free Replicated Data Types)
  * 💬 **Комментарии и обсуждения** — привязка комментариев к конкретным частям текста, ветки дискуссий, упоминания (@username)
  * 📊 **История изменений** — версионирование через Git-подобную систему, откат к предыдущим версиям, сравнение изменений (diff view)
  * 🏆 **Система репутации** — рейтинг пользователей на основе качества лекций, полезности правок, активности помощи другим
  * 🔔 **Уведомления** — оповещения о новых правках, комментариях, когда одногруппники загрузили лекцию по вашему предмету
  * 👨‍🎓 **Группы и команды** — создание учебных групп (курс/факультет), приватные пространства с общей базой лекций
  * 🎖️ **Бейджи и достижения** — награды за вклад ("Помог 10 студентам", "Загрузил 50 лекций", "Эксперт по математике")
  * 🔍 **Умный поиск** — поиск лекций не только по названию, но и по содержимому через семантический поиск и тегирование
  * 📤 **Пакетный экспорт** — скачивание всех лекций группы одним архивом для офлайн-доступа
  
  **Техническая реализация:** PostgreSQL для метаданных, Yjs/Automerge для CRDT, Socket.io для WebSocket, Redis для кэша активных сессий, MinIO/S3 для хранения файлов, Elasticsearch для полнотекстового поиска
- **Интерактивная доска для лекций** — многофункциональное полотно для визуализации учебного материала с возможностями:
  * 🖊️ **Рисование и аннотации** — свободное рисование стилусом/мышью с настройкой толщины линии, цвета, текстур (маркер, карандаш, кисть)
  * 📝 **Текстовые блоки** — размещение, редактирование и стилизация текста с поддержкой LaTeX для математических формул
  * 📊 **Автогенерация графиков** — AI создаёт диаграммы, схемы, mind maps на основе текста лекции через библиотеки D3.js/Chart.js
  * 🧩 **Умные блоки** — готовые шаблоны для формул, определений, примеров с автозаполнением из конспекта
  * 🎨 **Слои и группировка** — многослойная структура для организации контента (фон → графики → текст → аннотации)
  * 📹 **Синхронизация с видео** — привязка элементов доски к таймкоду лекции, воспроизведение анимаций по ходу объяснения
  * 💾 **Экспорт презентаций** — сохранение в PNG/PDF/PowerPoint с возможностью анимированного воспроизведения
  * 👥 **Коллаборативное редактирование** — real-time совместная работа через WebSocket, каждый пользователь видит курсоры других
  * 🤖 **AI-помощник доски** — автоматические предложения визуализации ("Нарисовать график функции?", "Добавить схему алгоритма?")
  
  **Техническая реализация:** Canvas API + Fabric.js для рендеринга, WebSocket для синхронизации, IndexedDB для локального кэша, FFmpeg для экспорта видео
- **Распределённая транскрибация** — сервер (Redis/RabbitMQ) раздаёт задачи на транскрибацию компам разработчиков через Celery-воркеры. У каждого разработчика кнопка вкл/выкл — транскрибирует только когда комп включён и владелец согласен. Результат возвращается на сервер
- **Docker + деплой на свой сервер** — контейнеризация через Docker Compose (FastAPI + React + Redis + PostgreSQL), покупка домена, доступ извне через Cloudflare Tunnel (бесплатно, не нужен статический IP)
- **Переход на faster-whisper** — замена openai-whisper на faster-whisper для всех пользователей без GPU: идентичное качество, в 4-6 раз быстрее на CPU, потребляет в 3 раза меньше RAM за счёт INT8 квантизации
