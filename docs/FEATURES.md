# 🌟 Student AI Assistant - Возможности и функционал

## 📖 О проекте

**Student AI Assistant** — это умный помощник для студентов, который превращает аудиозаписи лекций в готовые учебные материалы всего за несколько кликов. Больше не нужно часами переписывать лекции вручную — искусственный интеллект сделает это за вас!

---

## 🎯 Для кого этот проект?

### 👨‍🎓 Студенты
- Не успеваете конспектировать на лекциях? Просто записывайте аудио!
- Готовитесь к экзамену? Получите автоматические шпаргалки и вопросы для самопроверки!
- Пропустили лекцию? Попросите у одногруппника запись — система создаст конспект!

### 👨‍🏫 Преподаватели
- Хотите дать студентам качественные конспекты? Запишите лекцию — система структурирует материал
- Нужны вопросы для контрольной? AI сгенерирует их автоматически на основе вашей лекции

### 📚 Любители самообразования
- Смотрите образовательные видео? Извлеките аудио и получите конспект!
- Слушаете подкасты? Превратите их в структурированный текст с ключевыми идеями!

## 🚀 Основной функционал

### 1. 🎙️ Транскрибация аудио в текст

**Что это?**
Загрузите аудиозапись лекции (или видео), и система автоматически распознает речь и превратит её в текст.

**Как это работает?**
1. Нажмите кнопку "Загрузить аудио"
2. Выберите файл (mp3, wav, m4a, mp4, и другие форматы)
3. Подождите 3-10 минут (зависит от длины записи)
4. Получите текстовую расшифровку лекции!

**Поддерживаемые форматы:**
- 🎵 Аудио: MP3, WAV, M4A, FLAC, OGG, OPUS
- 🎬 Видео: MP4, MOV, AVI, MKV, WEBM

**Время обработки:**
- 5 минут аудио → ~1 минута обработки
- 30 минут аудио → ~5 минут обработки
- 60 минут аудио → ~10 минут обработки

**Особенности:**
- ✅ Работает полностью офлайн (без интернета для транскрибации)
- ✅ Поддержка русского языка с автоопределением
- ✅ Высокое качество распознавания речи
- ✅ Бесплатно, без лимитов

---

### 2. 🧹 Умная очистка текста

**Что это?**
После транскрибации текст может содержать ошибки распознавания, слова-паразиты и опечатки. AI автоматически исправит все это!

**Что исправляет:**
- ❌ "эээ сегодня мы рассмотрим масинное абучение ну вот"
- ✅ "Сегодня мы рассмотрим машинное обучение"

**Типы исправлений:**
1. **Орфографические ошибки**
   - "масинное" → "машинное"
   - "интиграл" → "интеграл"
   - "програмирование" → "программирование"

2. **Фразы-паразиты**
   - Удаление: "ээ", "ну", "вот", "значит", "как бы", "в общем"
   - "ну вот значит это ээ важно" → "Это важно"

3. **Технические термины**
   - SQL команды: "делит фрог" → "DELETE FROM"
   - Формулы: "икс квадрат плюс игрек" → "x² + y"
   - Языки программирования: правильное написание Python, JavaScript, и др.

4. **Форматирование**
   - Автоматическое разбиение на абзацы
   - Правильная пунктуация
   - Структурирование текста

**Режимы:**
- 🤖 **С AI-фильтром** - чистый, исправленный текст (рекомендуется)
- ⚡ **Без фильтра** - сырая транскрибация (для быстрого просмотра)

### 3. 📝 Создание конспектов

**Что это?**
AI прочитает вашу лекцию и создаст краткий структурированный конспект с самым важным.

**Что получите:**
- 📚 Название темы
- 🎯 Основные тезисы и идеи
- 📖 Ключевые термины с определениями
- 💡 Важные формулы и правила
- ✅ Выводы и итоги

**Пример структуры конспекта:**
```
# 📚 Машинное обучение: Основы

## 🎯 Основные тезисы
- Машинное обучение — способность компьютеров учиться без программирования
- Существует 3 основных типа: обучение с учителем, без учителя, с подкреплением
- Используется для распознавания образов, рекомендательных систем, прогнозирования

## 📖 Ключевые термины
**Нейронная сеть** — математическая модель, имитирующая работу мозга
**Обучающая выборка** — набор данных для тренировки модели
**Переобучение** — когда модель слишком точно подстраивается под обучающие данные

## ✅ Выводы
Машинное обучение революционизирует технологии...
```

**Преимущества:**
- ⚡ Сокращает текст до ~30% от оригинала
- 📊 Структурированный формат (легко читать)
- 🎨 Использует эмодзи для наглядности
- ✨ Сохраняет всю важную информацию

**Время создания:** 30-40 секунд

### 4. 📚 Извлечение терминов

**Что это?**
Система найдет все ключевые термины и понятия в лекции и даст их определения.

**Что получите:**
Справочник терминов с четкими определениями в формате словаря.

**Пример:**
```
📚 Ключевые термины и определения

**Алгоритм** — последовательность инструкций для решения задачи

**Переменная** — именованное хранилище данных в программе

**Функция** — блок кода, выполняющий определенную задачу

**Массив** — структура данных для хранения нескольких элементов

**Цикл** — многократное выполнение одного и того же кода
```

**Для чего это нужно:**
- 📖 Создание глоссария к лекции
- 🔍 Быстрый поиск определений
- 📝 Подготовка к экзаменам
- 💡 Понимание сложных терминов

**Время создания:** 30-40 секунд

### 5. ❓ Генерация вопросов для самопроверки

**Что это?**
AI создаст вопросы по материалу лекции, чтобы вы могли проверить, насколько хорошо усвоили тему.

**Типы вопросов:**
1. **Определения** - "Что такое нейронная сеть?"
2. **Объяснения** - "Объясните разницу между обучением с учителем и без учителя"
3. **Применение** - "Где используется машинное обучение?"
4. **Сравнение** - "Чем отличается переобучение от недообучения?"

**Пример:**
```
❓ Вопросы для самопроверки

1. Что такое машинное обучение?
2. Перечислите три основных типа машинного обучения
3. Что такое нейронная сеть и как она работает?
4. Объясните, что такое переобучение модели
5. Приведите примеры применения машинного обучения в жизни
6. В чем разница между обучающей и тестовой выборками?
7. Что такое градиентный спуск?
8. Какие метрики используются для оценки качества модели?
```

**Для чего это нужно:**
- ✅ Подготовка к экзамену или зачету
- 🎯 Проверка усвоения материала
- 📝 Создание билетов для контрольной
- 💡 Выявление пробелов в знаниях

**Время создания:** 20-30 секунд

### 6. 🧾 Создание шпаргалок

**Что это?**
Компактная памятка с самым важным — идеальный формат для быстрого повторения перед экзаменом.

**Что включает:**
- 📌 Ключевые определения (1-2 строки)
- 🧠 Основные идеи и правила
- 🔢 Формулы с пояснениями
- 🛠️ Алгоритмы и процедуры (пошагово)
- ⚠️ Типичные ошибки
- 💡 Мнемоники и лайфхаки
- ✅ Быстрая самопроверка

**Пример шпаргалки:**
```
# 🧾 Шпаргалка: SQL Основы

## 📌 Ключевые команды
- SELECT → выбор данных из таблицы
- INSERT → добавление новых строк
- UPDATE → изменение существующих данных
- DELETE → удаление строк
- JOIN → объединение таблиц

## 🔢 Синтаксис
SELECT столбец FROM таблица WHERE условие;
INSERT INTO таблица (столбцы) VALUES (значения);
UPDATE таблица SET столбец = значение WHERE условие;

## ⚠️ Типичные ошибки
- Забыть WHERE в UPDATE/DELETE → изменятся ВСЕ строки!
- Не закрыть кавычки в строках
- Перепутать = (присваивание) и == (сравнение)

## 💡 Лайфхаки
- Используй LIMIT для проверки запроса на малой выборке
- Всегда сначала SELECT, потом DELETE/UPDATE
```

**Для чего это нужно:**
- ⚡ Быстрое повторение перед экзаменом
- 📝 Компактная справка (можно распечатать)
- 🎯 Выжимка самого важного
- 💾 Удобно сохранить на телефон

**Время создания:** 20-30 секунд

### 7. 🔍 Расширенные конспекты с подробным разбором

**Что это?**
Глубокое изучение темы с максимально подробным объяснением каждого термина.

**Что получите:**
Для каждого ключевого термина:
- 📖 Академическое определение
- 📝 Подробное объяснение (2-3 абзаца)
- 🌍 Контекст и применение
- 🔗 Связи с другими понятиями
- ⭐ Практическая важность
- 💡 Конкретные примеры

**Пример:**
```
### Нейронная сеть

**Определение:** Математическая модель, состоящая из связанных искусственных нейронов, способная обучаться на данных для решения сложных задач.

**Подробное объяснение:**
Нейронная сеть вдохновлена работой биологического мозга. Она состоит из слоев нейронов: входного (получает данные), скрытых (обрабатывают информацию) и выходного (дает результат). Каждый нейрон получает сигналы, взвешивает их важность и передает дальше.

Обучение сети происходит через корректировку весов связей между нейронами. Сеть "смотрит" на правильные ответы и постепенно улучшает свои предсказания, уменьшая ошибки на каждой итерации.

**Контекст и применение:**
Используется в компьютерном зрении (распознавание лиц), обработке естественного языка (ChatGPT), медицинской диагностике, беспилотных автомобилях, рекомендательных системах.

**Связи с другими понятиями:**
- Связана с машинным обучением (частный случай)
- Использует градиентный спуск для обучения
- Может страдать от переобучения
- Требует большие обучающие выборки

**Практическая важность:**
Основа современного AI. 90% прорывов последних лет (GPT, DALL-E, AlphaGo) основаны на нейросетях.

**Примеры:**
- Сверточные сети (CNN) для анализа изображений
- Рекуррентные сети (RNN) для текста и временных рядов
- Трансформеры (GPT) для генерации текста
```

**Для чего это нужно:**
- 📚 Глубокое изучение сложной темы
- 🎓 Подготовка к устному экзамену
- 📖 Создание справочника по терминам
- 💡 Понимание всех аспектов темы

**Объем:** В 2-3 раза больше исходного текста  
**Время создания:** 60-90 секунд

### 8. 💬 Расширение сложных тем

**Что это?**
Встретили непонятный термин или концепцию? AI даст подробное объяснение простым языком.

**Как использовать:**
1. Выделите сложный термин или тему
2. Выберите режим "Расширить тему"
3. Получите детальное объяснение с примерами

**Пример запроса:** "Квантовая запутанность"

**Что получите:**
```
🔍 Подробное объяснение: Квантовая запутанность

**Простыми словами:**
Представьте две волшебные монетки. Если одна выпадает орлом, вторая МГНОВЕННО становится решкой, даже если они на разных концах Вселенной. Это невозможно в обычном мире, но в квантовой физике — реальность!

**Научное объяснение:**
Квантовая запутанность — явление, при котором квантовые состояния двух частиц оказываются взаимосвязанными таким образом, что измерение одной частицы мгновенно влияет на состояние другой, независимо от расстояния между ними.

**Примеры:**
- Квантовые компьютеры используют запутанность для параллельных вычислений
- Квантовая криптография создает абсолютно защищенную связь
- Эксперименты с фотонами доказали запутанность на расстояниях более 1000 км

**Почему это важно:**
Открывает путь к квантовым технологиям будущего: сверхмощные компьютеры, телепортация информации, безопасная связь.

**Заблуждения:**
❌ "Информация передается быстрее света" — НЕТ, полезная информация не передается
❌ "Это мистика" — НЕТ, это проверяемое физическое явление
✅ "Это странно и противоречит интуиции" — ДА!
```

**Для чего это нужно:**
- 🤔 Понимание сложных концепций
- 📚 Дополнительный материал к лекции
- 💡 Разные уровни объяснения (от простого к сложному)
- 🎯 Примеры из реальной жизни

**Время создания:** 40-50 секунд

## 💡 Типичные сценарии использования

### 📚 Сценарий 1: Подготовка к экзамену

**Ситуация:** Через неделю экзамен, есть аудиозаписи всех лекций за семестр

**Что делать:**
1. Загрузите первую запись → Транскрибация
2. Примените AI-фильтр → Чистый текст
3. Создайте **конспект** → Основные тезисы
4. Создайте **шпаргалку** → Памятка для повторения
5. Создайте **вопросы** → Проверьте себя
6. Экспортируйте в PDF
7. Повторите для остальных лекций

**Результат:** Полный набор материалов для подготовки за 1-2 часа вместо нескольких дней!

---

### 🎓 Сценарий 2: Пропущенная лекция

**Ситуация:** Пропустили лекцию, одногруппник дал аудиозапись

**Что делать:**
1. Загрузите запись
2. Транскрибация + фильтрация
3. Создайте **расширенный конспект** → Подробный разбор всех терминов
4. Если что-то непонятно → **Расширьте тему**
5. Экспортируйте и изучайте

**Результат:** Полное понимание темы, как будто присутствовали на лекции!

---

### 📖 Сценарий 3: Создание справочника

**Ситуация:** Нужен справочник терминов по всему курсу

**Что делать:**
1. Загрузите записи всех лекций (можно по одной)
2. Для каждой лекции используйте **Извлечение терминов**
3. Скопируйте все термины в один документ
4. Экспортируйте в DOCX
5. Отредактируйте и дополните при необходимости

**Результат:** Профессиональный глоссарий по всему курсу!

---

### 🎯 Сценарий 4: Быстрое повторение

**Ситуация:** Завтра контрольная, нужно быстро повторить 5 тем

**Что делать:**
1. Для каждой темы создайте **шпаргалку**
2. Распечатайте или сохраните на телефон
3. Быстро пробегитесь по всем шпаргалкам
4. Проверьте себя по **вопросам для самопроверки**

**Результат:** Эффективное повторение за 30-40 минут вместо нескольких часов!

---

### 🏫 Сценарий 5: Помощь преподавателю

**Ситуация:** Вы преподаватель, нужны материалы для студентов

**Что делать:**
1. Запишите свою лекцию
2. Создайте **конспект** → Раздайте студентам
3. Создайте **вопросы** → Используйте для контрольной
4. Создайте **термины** → Дайте как справочник
5. Создайте **шпаргалку** → Памятка перед экзаменом

**Результат:** Полный набор учебных материалов за 10 минут!

## 🚀 Начало работы

### За 3 простых шага:

**Шаг 1: Загрузите аудио** 🎙️
- Перейдите в раздел "Транскрибатор"
- Нажмите "Загрузить аудио"
- Выберите файл (mp3, wav, m4a, mp4...)

**Шаг 2: Получите текст** ✨
- Дождитесь транскрибации (3-10 мин)
- Выберите: с AI-фильтром или без
- Текст появится в редакторе

**Шаг 3: Обработайте** 🤖
- Выберите режим (конспект, термины, вопросы...)
- Нажмите "Обработать"
- Экспортируйте результат!

## 💬 Часто задаваемые вопросы

**Q: Сколько это стоит?**  
A: Транскрибация абсолютно бесплатна (работает локально)! AI-обработка требует API ключ VseLLM - стоимость зависит от использования (подробности на https://vsellm.ru).

**Q: Какие языки поддерживаются?**  
A: Русский язык (можно добавить английский и другие).

**Q: Какой максимальный размер файла?**  
A: До 100 МБ (~90 минут аудио хорошего качества).

**Q: Нужен ли интернет?**  
A: Для транскрибации - НЕТ (работает офлайн). Для AI-обработки - ДА (обращается к DeepSeek API через VseLLM).

**Q: Как точно работает распознавание?**  
A: Очень точно! Использует модель Whisper от OpenAI с точностью ~95% для русского языка.

**Q: Можно ли редактировать результат?**  
A: Да! Встроенный WYSIWYG редактор позволяет править текст как угодно.

**Q: Сохраняются ли мои файлы?**  
A: Пока нет функции облачного хранения, но вы можете экспортировать всё на свой компьютер.

**Q: Работает ли на телефоне?**  
A: Сейчас только веб-версия для компьютера. Мобильное приложение в планах!
