# 🚀 Быстрый старт: Транскрибация аудио

Краткая инструкция для начала работы с транскрибацией аудио на сайте.

## ⚡ За 5 минут

### 1️⃣ Установите FFmpeg

**Windows (PowerShell от администратора):**
```powershell
choco install ffmpeg
```

**macOS:**
```bash
brew install ffmpeg
```

**Linux:**
```bash
sudo apt install ffmpeg
```

### 2️⃣ Установите Python зависимости

```bash
pip install -r requirements.txt
```

⏳ Займет 5-15 минут (скачивается PyTorch ~1-2 ГБ)

### 3️⃣ Загрузите модель Whisper Small

```bash
python download_model.py
```

В меню выберите `small` или просто нажмите `3`

⏳ Займет 2-5 минут (~500 МБ)

### 4️⃣ Запустите API сервер

**Windows:**
```bash
start_api_small.bat
```

**macOS/Linux:**
```bash
chmod +x start_api_small.sh
./start_api_small.sh
```

Сервер запустится на http://localhost:8000

### 5️⃣ Запустите React приложение

В новом терминале:

```bash
npm start
```

Сайт откроется на http://localhost:3000

### 6️⃣ Используйте транскрибацию

1. Откройте http://localhost:3000
2. Войдите в личный кабинет
3. Раздел **"Транскрибатор аудио в текст"**
4. Загрузите аудиофайл (mp3, wav и др.)
5. Дождитесь завершения
6. Текст появится в редакторе!
