## 🎯 Введение

Мы перешли на **локальную транскрибацию** с использованием Whisper от OpenAI, чтобы:

- ✅ Не платить за API при тестировании
- ✅ Работать полностью офлайн
- ✅ Транскрибировать файлы без ограничений по размеру
- ✅ Получать отличное качество распознавания речи

**Важно:** Локальная транскрибация требует мощного компьютера. Для длинных лекций (1+ час) процесс может занять 20-40 минут.

## 💻 Системные требования

### Минимальные требования:

- **ОС:** Windows 10/11, macOS 10.15+, Linux (Ubuntu 20.04+)
- **Python:** 3.12
- **RAM:** минимум 4 ГБ (рекомендуется 8 ГБ+)
- **Место на диске:**
  - Модель `base`: 500 МБ
  - Модель `small`: 1 ГБ
  - Модель `medium`: 2.5 ГБ
- **Процессор:** любой современный (Intel i3+, AMD Ryzen 3+)

### Рекомендуемые требования:

- **RAM:** 16 ГБ+
- **GPU:** NVIDIA GPU с CUDA (ускорение в 5-10 раз!)
- **Процессор:** Intel i5/i7, AMD Ryzen 5/7

### Проверка Python:

```bash
python --version
```

Должно быть `Python 3.12.0` или выше.

Если Python не установлен: https://www.python.org/downloads/

### Шаг 2: Установка FFmpeg

FFmpeg необходим для обработки аудиофайлов различных форматов.

#### 🪟 Windows

**Вариант А: Через Chocolatey (рекомендуется)**

1. Откройте **PowerShell от имени администратора**
2. Установите Chocolatey (если ещё нет):
   ```powershell
   Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
   ```
3. Установите FFmpeg:
   ```powershell
   choco install ffmpeg
   ```

**Вариант Б: Ручная установка**

1. Скачайте FFmpeg: https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
2. Распакуйте в `C:\ffmpeg\`
3. Добавьте в PATH:
   - Нажмите `Win + R` → введите `sysdm.cpl` → Enter
   - Вкладка **"Дополнительно"**
   - Кнопка **"Переменные среды"**
   - В разделе "Системные переменные" найдите `Path` → **"Изменить"**
   - Нажмите **"Создать"** → введите `C:\ffmpeg\bin`
   - **OK** → **OK** → **OK**
4. **Перезапустите** командную строку или VS Code

#### 🍎 macOS

```bash
brew install ffmpeg
```

Если Homebrew не установлен:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

#### 🐧 Linux (Ubuntu/Debian)

```bash
sudo apt update
sudo apt install ffmpeg
```

**Для других дистрибутивов:**

- Fedora: `sudo dnf install ffmpeg`
- Arch: `sudo pacman -S ffmpeg`

#### ✅ Проверка установки FFmpeg:

```bash
ffmpeg -version
```

**Должно вывести:**

```
ffmpeg version 8.0-essentials_build-www.gyan.dev Copyright (c) 2000-2025 the FFmpeg developers
...
```

Если команда не найдена — FFmpeg не установлен или не добавлен в PATH.

### Как сменить модель

**Вариант 1: Через переменную окружения**

Создайте или отредактируйте файл `.env` в корне проекта:

```env
WHISPER_MODEL=small
```

**Вариант 2: В коде**

Откройте `api/transcribe.py`, найдите строку (~22):

```python
_model_name = os.getenv('WHISPER_MODEL', 'base')
```

Замените на:

```python
_model_name = os.getenv('WHISPER_MODEL', 'small')  # или 'medium'
```

**Вариант 3: Загрузите несколько моделей**

Вы можете иметь несколько моделей и менять их по необходимости:

```bash

# Введите: small

# Введите: medium
```

Затем меняйте в `.env` или в коде.

## ⚡ Оптимизация производительности

### Ускорение с помощью GPU (NVIDIA)

Если у вас есть видеокарта NVIDIA, транскрибация будет в **5-10 раз быстрее**!

#### Проверка доступности GPU:

```bash
python -c "import torch; print(f'CUDA доступна: {torch.cuda.is_available()}')"
```

**Если вывод: `CUDA доступна: True`** — всё отлично, GPU работает! 🎉

**Если вывод: `CUDA доступна: False`** — нужна установка CUDA:

#### Установка CUDA (для GPU):

1. **Проверьте версию драйвера NVIDIA:**
   ```bash
   nvidia-smi
   ```
2. **Скачайте CUDA Toolkit:**

   - Ссылка: https://developer.nvidia.com/cuda-downloads
   - Выберите вашу ОС и версию
   - Установите

3. **Переустановите PyTorch с поддержкой CUDA:**

   ```bash
   pip uninstall torch torchaudio
   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu118
   ```

4. **Проверьте снова:**
   ```bash
   python -c "import torch; print(f'CUDA: {torch.cuda.is_available()}')"
   ```

### Разбиение длинных файлов

Для очень длинных лекций (2+ часа) рекомендуется разбить файл на части.

**Использование `split_audio.py`:**

1. Установите дополнительную библиотеку:

   ```bash
   pip install pydub
   ```

2. Откройте `split_audio.py` и укажите путь к файлу:

   ```python
   file_path = "C:/path/to/long_lecture.mp3"
   chunk_minutes = 30  # Разбить на части по 30 минут
   ```

3. Запустите:

   ```bash
   python split_audio.py
   ```

4. Транскрибируйте каждую часть отдельно.

## 🛠️ Решение проблем

### ❌ Ошибка: "No module named 'whisper'"

**Решение:**

```bash
pip install openai-whisper
```

---

### ❌ Ошибка: "ffmpeg not found" или "RuntimeError: Failed to run ffmpeg"

**Причина:** FFmpeg не установлен или не добавлен в PATH.

**Решение:**

1. Проверьте установку: `ffmpeg -version`
2. Если команда не найдена — переустановите FFmpeg (см. Шаг 2)
3. **Перезапустите** командную строку/терминал после установки
4. На Windows проверьте PATH (должен быть `C:\ffmpeg\bin`)

---

### ❌ Ошибка: "OutOfMemoryError" или "CUDA out of memory"

**Причина:** Недостаточно RAM или VRAM (на GPU).

**Решение:**

1. Используйте меньшую модель (`base` вместо `small`)
2. Закройте другие программы
3. Разбейте аудио на части (см. `split_audio.py`)
4. Если на GPU — уменьшите batch size (по умолчанию уже минимальный)

---

### ❌ Транскрибация очень медленная

**Причины и решения:**

1. **Нет GPU:**
   - Время транскрибации на CPU в 5-10 раз дольше — это нормально
   - Используйте модель `base` для тестов
2. **Слабый процессор:**
   - Рассмотрите использование облачного сервера с GPU
   - Или разбейте файл на части
3. **Большой файл:**
   - Разбейте на части по 30-60 минут

---

### ❌ Транскрибация на английском, хотя аудио на русском

**Причина:** Модель автоматически определила язык неправильно.

**Решение:**

Откройте `api/transcribe.py`, найдите строку (~115):

```python
result = model.transcribe(
    temp_file_path,
    language='ru',  # ← Убедитесь, что здесь 'ru'
    ...
)
```

Если стоит `language=None` или другой язык — измените на `'ru'`.

---

### ❌ Ошибка: "Model not found"

**Причина:** Модель не загружена.

**Решение:**

```bash
python scripts/download_model.py
```

Выберите модель (например, `base`) и дождитесь загрузки.

---

### ❌ Качество транскрибации плохое

**Решение:**

1. **Используйте лучшую модель:**
   - Вместо `base` используйте `small` или `medium`
2. **Проверьте качество аудио:**
   - Плохая запись = плохая транскрибация
   - Используйте чистую запись без шумов
3. **Укажите правильный язык:**
   - Убедитесь, что `language='ru'` для русского

---

### ❌ Whisper "зависает" на длинных файлах

**Причина:** Недостаточно RAM или очень длинный файл.

**Решение:**

1. Разбейте файл на части (используйте `split_audio.py`)
2. Увеличьте RAM (закройте другие программы)
3. Используйте модель `base` (требует меньше памяти)

## ❓ FAQ

### Вопрос: Сколько места занимают модели?

**Ответ:**

- `tiny`: ~75 MB
- `base`: ~150 MB
- `small`: ~500 MB
- `medium`: ~1.5 GB
- `large`: ~3 GB

Модели хранятся в `whisper_models/` внутри проекта.

---

### Вопрос: Можно ли работать без интернета?

**Ответ:** Да! После загрузки модели интернет не нужен. Всё работает полностью офлайн.

---

### Вопрос: Какую модель выбрать для длинных лекций (1-2 часа)?

**Ответ:**

- Для тестов: `base`
- Для продакшена: `small` или `medium`
- Если есть время: `medium` даст лучшее качество

---

### Вопрос: Поддерживаются ли другие языки кроме русского?

**Ответ:** Да! Whisper поддерживает 98 языков. Измените в коде:

```python
language='en'  # английский
language='de'  # немецкий
language=None  # автоопределение
```

---

### Вопрос: Можно ли использовать несколько моделей одновременно?

**Ответ:** Нет, но вы можете загрузить несколько моделей и переключаться между ними, меняя переменную `WHISPER_MODEL` в `.env`.

---

### Вопрос: Будет ли работать на Mac M1/M2?

**Ответ:** Да! PyTorch поддерживает Apple Silicon. Транскрибация будет быстрее, чем на обычном CPU.

---

### Вопрос: Как ускорить транскрибацию?

**Ответ:**

1. Используйте GPU (NVIDIA с CUDA) — ускорение в 5-10 раз
2. Используйте меньшую модель (`base` быстрее, чем `medium`)
3. Разбейте длинные файлы на части
4. На Mac M1/M2 используйте MPS (автоматически)

---

### Вопрос: Сколько стоит локальный Whisper?

**Ответ:** **Полностью бесплатно!** 🎉 Нет ограничений по количеству транскрибаций.

## 🌐 Использование на веб-сайте

После установки и тестирования вы можете использовать транскрибацию прямо на сайте в личном кабинете.

### Шаг 1: Запуск проекта

**Windows** — двойной клик по `run.bat`

**Linux / macOS:**
```bash
./run.sh
```

Скрипт автоматически запустит API сервер (http://localhost:8000) и фронтенд (http://localhost:3000).

### Шаг 3: Использование транскрибации

1. Откройте сайт в браузере: `http://localhost:3000`
2. Войдите в личный кабинет
3. Перейдите в раздел **"Транскрибатор аудио в текст"**
4. Нажмите **"Выбрать файл"** и загрузите аудио (до 100 МБ)
5. Дождитесь завершения обработки (появится модальное окно с прогрессом)
6. После обработки вы автоматически перейдете в раздел **"Обработка текста с помощью ИИ"**
7. Транскрибированный текст появится в редакторе
8. Теперь вы можете обработать текст с помощью AI или экспортировать его

### 📋 Поддерживаемые форматы

- **Аудио:** mp3, wav, m4a, flac, ogg, opus
- **Видео:** mp4, mov, avi, mkv, webm
- **Размер:** до 100 МБ (~90 минут записи)

### ⏱️ Время обработки

Зависит от длины аудио и модели:

- **5 минут аудио:** ~30 секунд - 1 минута
- **30 минут аудио:** ~3-5 минут
- **60 минут аудио:** ~6-10 минут

**💡 Совет:** Для длинных лекций (60+ минут) используйте модель `small` или `medium`.

### 🔧 Смена модели

Если хотите использовать другую модель:

1. Остановите API сервер (Ctrl+C)
2. Измените переменную окружения:
   - Windows: `set WHISPER_MODEL=medium`
   - Linux/Mac: `export WHISPER_MODEL=medium`
3. Запустите API снова: `run.bat` / `./run.sh`

Доступные модели: `tiny`, `base`, `small`, `medium`, `large`
