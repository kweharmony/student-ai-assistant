# 📝 Changelog: Интеграция транскрибации Whisper на веб-сайт

## 🎉 Что добавлено

### Frontend (React)

**Файл: `src/components/AccountPage.tsx`**

1. **Новые состояния:**
   - `isTranscribing` - флаг процесса транскрибации
   - `transcriptionProgress` - текст текущего этапа обработки
   - `transcriptionError` - сообщение об ошибке

2. **Функция `handleAudioTranscription(file)`:**
   - Отправляет аудиофайл на API endpoint `/api/transcribe/audio`
   - Показывает прогресс обработки
   - При успехе: вставляет текст в редактор и переключает на раздел "Обработка текста с помощью ИИ"
   - При ошибке: показывает модальное окно с описанием проблемы

3. **Обновлена кнопка загрузки файла:**
   - Принимает аудио и видео форматы: mp3, wav, m4a, flac, ogg, opus, mp4, mov, avi, mkv, webm
   - Ограничение размера: 100 МБ (~90 минут аудио)
   - Вызывает `handleAudioTranscription()` при выборе файла

4. **Модальное окно прогресса:**
   - Анимированный спиннер
   - Прогресс-бар с градиентом
   - Информационное сообщение о времени обработки
   - Нельзя закрыть во время обработки

5. **Модальное окно ошибки:**
   - Красная иконка с предупреждением
   - Описание ошибки
   - Кнопка "Понятно" для закрытия

### Backend (Python)

**Файл: `api/transcribe.py`** (уже существовал)
- Endpoint: `POST /api/transcribe/audio`
- Использует модель Whisper (загружается через переменную окружения `WHISPER_MODEL`)
- Поддерживает все популярные аудио и видео форматы
- Возвращает транскрибированный текст с метаданными

### Скрипты запуска

1. **`start_api_small.bat`** (Windows)
   - Активирует виртуальное окружение
   - Устанавливает `WHISPER_MODEL=small`
   - Запускает API сервер

2. **`start_api_small.sh`** (macOS/Linux)
   - Активирует виртуальное окружение
   - Устанавливает `WHISPER_MODEL=small`
   - Запускает API сервер

## 🔧 Как работает интеграция

```
[Frontend]                    [Backend]
   │                              │
   ├─ Пользователь выбирает файл │
   │                              │
   ├─ handleAudioTranscription() │
   │      ↓                       │
   ├─ FormData с файлом          │
   │      ↓                       │
   ├─ POST /api/transcribe/audio →│
   │                              │
   │                         ┌────┴────┐
   │                         │ Whisper │
   │                         │  Model  │
   │                         │ (small) │
   │                         └────┬────┘
   │                              ↓
   │                      Транскрибация
   │                              ↓
   │← JSON с текстом ─────────────┤
   ↓                              │
Текст в редактор                  │
   ↓                              │
Переключение на                   │
"Обработка текста"                │
```

## 📦 Размеры моделей

| Модель | Размер | Качество | Рекомендация |
|--------|--------|----------|--------------|
| tiny   | ~75 MB | Низкое | Тесты |
| base   | ~150 MB | Среднее | Быстрая проверка |
| **small** | **~500 MB** | **Хорошее** | **Лекции** ⭐ |
| medium | ~1.5 GB | Очень хорошее | Длинные лекции |
| large  | ~3 GB | Максимальное | Профессиональное |

## ⏱️ Время обработки (модель small)

- **5 минут аудио:** ~30 сек - 1 мин
- **30 минут аудио:** ~3-5 мин
- **60 минут аудио:** ~6-10 мин

*Время зависит от производительности CPU*

## 🎯 Workflow пользователя

1. Пользователь записывает лекцию на диктофон
2. Загружает аудио на сайт через раздел "Транскрибатор"
3. Ждет 3-10 минут (в зависимости от длины)
4. Получает транскрибированный текст в редакторе
5. Обрабатывает текст с помощью AI (конспект, термины и др.)
6. Экспортирует результат в PDF/DOCX/TXT

## 🐛 Troubleshooting

### Ошибка: "Failed to fetch"
- API сервер не запущен
- Решение: запустите `start_api_small.bat` или `start_api_small.sh`

### Ошибка: "Whisper model not found"
- Модель не загружена
- Решение: `python download_model.py` и выберите `small`

### Ошибка: "FFmpeg not found"
- FFmpeg не установлен или не в PATH
- Решение: см. `WHISPER_INSTALL.md` раздел "Установка FFmpeg"

### Долгая обработка
- Используется слабая модель или длинное аудио
- Решение: используйте модель `small` или `medium` для длинных лекций

## ✅ Проверка установки

1. FFmpeg установлен: `ffmpeg -version`
2. Модель загружена: проверьте `~/.cache/whisper/`
3. API работает: откройте http://localhost:8000/docs
4. Тест: http://localhost:8000/api/transcribe/health
