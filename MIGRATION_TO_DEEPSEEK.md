## 🔧 Инструкция по запуску

### Шаг 1: Обновите зависимости

```bash
# Удалите старые зависимости
pip uninstall google-generativeai -y

# Установите новые зависимости
pip install -r requirements.txt
```

### Шаг 2: Настройте .env файл

Скопируйте `.env.example` в `.env` и заполните:

```bash
cp .env.example .env
```

Откройте `.env` и добавьте ваш API ключ:

```env
# Ваш API ключ от VseLLM
DEEPSEEK_API_KEY=vsellm_ваш_ключ_здесь

# Base URL (оставьте как есть)
DEEPSEEK_BASE_URL=https://api.vsellm.ru/v1

# Модель (рекомендуется)
DEEPSEEK_MODEL=deepseek/deepseek-v3.2
```

**Где получить API ключ:**
1. Зарегистрируйтесь на https://vsellm.ru
2. Перейдите в раздел "Ключи"
3. Сгенерируйте новый ключ (начинается с `vsellm_`)
4. Пополните баланс (если требуется)

### Шаг 3: Запустите сервер

```bash
# Windows
.\start_api_medium.bat

# Linux/Mac
./start_api_medium.sh

# Или напрямую
python -m uvicorn api.app:app --reload --host 0.0.0.0 --port 8000
```

### Шаг 4: Проверьте работу

**Health check:**
```bash
curl http://localhost:8000/api/ml/health
```

Ожидаемый ответ:
```json
{
  "status": "healthy",
  "gemini_api_available": true,
  "message": "DeepSeek API работает корректно",
  "timestamp": "2026-02-06T..."
}
```

**Тестовый запрос:**
```bash
curl -X POST http://localhost:8000/api/ml/process \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Квантовая механика — раздел физики...",
    "mode": "summarize"
  }'
```

## 🎯 Новые возможности

### Multi-Step Generation

Для длинных конспектов (`detailed_notes` и больших `summarize`) используется **Multi-Step Generation**:

1. **Шаг 1:** Анализ структуры → выделение 3-5 тем
2. **Шаг 2:** Параллельная генерация конспекта по каждой теме (до 6500 токенов)
3. **Шаг 3:** Объединение частей в финальный документ

**Преимущества:**
- ✅ Обход лимита 7k токенов
- ✅ Параллельная обработка (быстрее)
- ✅ Лучшая фокусировка на каждой теме
- ✅ Устойчивость к ошибкам (если одна тема провалилась, другие OK)

### Асинхронная обработка

Все запросы теперь асинхронные:
- Параллельная обработка нескольких пользователей
- Более высокая пропускная способность
- Лучшая производительность

## 🐛 Устранение неполадок

### Ошибка: "DEEPSEEK_API_KEY не найден"

**Решение:**
- Проверьте, что файл `.env` существует в корне проекта
- Убедитесь, что переменная `DEEPSEEK_API_KEY` заполнена
- Перезапустите сервер после изменения `.env`

### Ошибка: "503 Service Unavailable" или "Rate Limit"

**Решение:**
- API перегружен, система автоматически повторит запрос (3 попытки)
- Проверьте баланс на https://vsellm.ru
- Уменьшите количество параллельных запросов

### Ошибка: "Connection timeout"

**Решение:**
- Проверьте интернет соединение
- Проверьте доступность https://api.vsellm.ru/v1
- Увеличьте таймаут в коде (если нужно)

### Конспект обрывается на середине

**Причина:** Лимит токенов модели (7k)

**Решение:** Система автоматически использует Multi-Step Generation для длинных текстов. Если проблема сохраняется:
- Уменьшите размер входного текста
- Используйте режим `summarize` вместо `detailed_notes`
