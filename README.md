# MindeSync - React версия

Транскрибация аудио в текст - React приложение с TypeScript и Tailwind CSS.

## Особенности

- ✅ Полностью адаптивный дизайн
- ✅ Переключение темы (светлая/темная)
- ✅ Функционал загрузки файлов с прогресс-баром
- ✅ Анимации и эффекты (плавающие облака)
- ✅ TypeScript для типобезопасности
- ✅ Tailwind CSS для стилизации
- ✅ Точное воспроизведение оригинального дизайна

## Установка и запуск

Изменение политики не «навсегда», а только для текущего активного сеанса PowerShell команда:

Set-ExecutionPolicy Unrestricted -Scope Process

1. Установите зависимости:

```bash
npm install
```

2. Запустите проект в режиме разработки:

```bash
npm start
```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## Сборка для продакшена

```bash
npm run build
```

Для возврата политики к значениям по умолчанию (обычно — Restricted) используется команда:

Set-ExecutionPolicy Default

## Структура проекта

```
├── components/          # React компоненты
│   ├── Header.tsx      # Шапка сайта
│   ├── Hero.tsx        # Главная секция

│   ├── UploadDemo.tsx  # Демо загрузки
│   ├── Features.tsx    # Особенности

├── index.tsx           # Точка входа
└── index.css          # Глобальные стили
```

## Технологии

- TypeScript

- Create React App

## Функционал

- **Переключение темы**: Кнопка в правом верхнем углу
- **Загрузка файлов**: Работает в обеих секциях с индикатором прогресса
- **Адаптивность**: Полностью адаптивный дизайн для всех устройств
- **Анимации**: Плавающие облака и плавные переходы
